# Rachel Tang — Portfolio

Static portfolio site for Rachel Tang, covering marketing strategy, product thinking, applied technology, and selected experience.

## Contents

- `index.html` — selected work and professional focus
- `experience.html` — experience and education
- `links.html` — contact and profile links
- `style.css` — shared visual styles

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server:

```bash
python3 -m http.server 8000
```

The general resume PDF is intentionally kept outside version control.
